## 2. AI NPC 举证（五段，直接进手记）

1. **状态可量化**：`relations.mjs:5`（`familiarity` / `trust`，中性 trust=30）、`:41-47`（带上限、trust 变化 ≥8 记史并带 `why`）；另有 drives（energy/social…）、viability 器官账本、`debt`。
2. **决策可校验**：`agent.mjs:454-457`（`validate()` → `actuate()`；非法则 `refused++` 并写 trace，不消耗资源）；`rules.mjs:validate` 是唯一闸门。
3. **阈值拒绝（可演示）**：`body.mjs:81` `TOWN_GATES = { tradeTrust: 30, compFam: 0.3, compTrust: 32 }`；`:318-330` 交易/合作前按信任与熟悉度判定 ⇒ "关系不到位就不交易、不合作"。
4. **记忆影响决策**：`memory.mjs`（每人 400 行记忆 + lastMemories），记忆进入候选生成与理由。
5. **可复现的对照**：`life/run.mjs:23` `simulate({seed,ticks,deliberator})`、`:177` `sweep({seeds})`；`host.mjs:452-467` 对照视图输出每侧 `cost{事件,被问,跳过,驳回重问}`、`researchViab`、`m3/coupling`。

**一句总结**：AI 的贡献不是"会聊天"，而是"在规则约束下改变世界"，且可被同种子复现。
