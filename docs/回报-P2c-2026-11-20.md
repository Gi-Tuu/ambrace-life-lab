## 0. 开工前四问（结论已验证）

### 0.1 `actor.pos` 迁移策略

唯一事实是 `w.pos[id] = {x,z,space}`（`space` 为 `'world'` 或 `'room:<room>'`），写入口只有一个文件：

- `life/actor-pos.mjs`
  - `placeActor(w,id,pos,{loc,room,mirror})`：一次写 `pos`，同步 `loc`/`occupancy`（保序索引），玩家额外同步 `survival.playerPos`/`campPlayerRoom` 镜像。
  - `moveActor(spawnActor/moveActor/initPositions/migratePositions/adoptPositions/adoptTravels/setLocOnly/setPlayerRoom/detachPlayerRoom/removeActor)`：读档、自愈、死亡、旅行索引的唯一入口。
  - `beginTravel/advanceTravelPos/clearTravel/noteArrival`：旅行仍是索引（`districtTravel`/`residentTravel`），但只由本文件写。
  - `constructionArrivals` 从来不是存储字段，`survView` 每次由 `residentTravel.at` 现算。
- 旧档：`migratePositions(w, raw.pos)` 先整体替换 pos（有 pos 的档逐位恢复），没有 pos 时按 `playerPos`（室内坐标按 `room:<campPlayerRoom>` 解释、不乘 16）/`residentTravel.at` / 客户端同名槽位表 `[sx-1+i%3, sy+floor(i/3)]` / 室内槽位表确定性补齐。
- 研究态/旧时间模型：不建 `w.pos`、不进 `dumpSurv`；旧字段语义不变，研究五面与 dumpSurv 逐位不变。
- 静态闸门：`P2c-03` 扫描 `life/*.mjs`，七个旧字段（`loc/occupancy/playerPos/campPlayerRoom/residentTravel/districtTravel/constructionArrivals`）的赋值只允许出现在 `actor-pos.mjs`、研究/城镇快照恢复（`host-world.mjs`）、离线夹具（`camp-instances/build-efficiency/capability`）。

### 0.2 房间 portal 数据

- `shared/room-layout.mjs`（新）：`ROOM_GRID/ROOM_BOUNDS`（256×192 画布）、`ROOM_UNITS`（16×12 世界单位）、`ROOM_DOOR_PX = [112,176,32,16]`、`ROOM_DOOR_WORLD = {x:7,z:11,w:2,d:1}`、`HALL_FRONT/hallFrontGeometry`（从 `web/hall-front.mjs` 移入；hall 门与默认门同矩形）、`ROOM_INTERIORS/PERSONAL_INTERIOR/YARD_PROPS/roomPropsPx`（家具规格，`roomStage` 的唯一输入）。
- `shared/camp-scene.mjs` 的 `roomStage` 改用 `ROOM_DOOR_PX`；`life/space.mjs` 新增 `roomSurface({stage,bounds,door,extraSolids})`：16×12 世界单位，`walkable` 复刻旧 `roomBodyFits` 的 bounds+门宽规则并查 stage 实心 AABB（含 hall 栏杆），`portalAt` 返回唯一的门 portal。
- `life/construction-access.mjs` 新增 `roomSpaceOf(w,room)`（按世界缓存，服务端与客户端同一份 `roomStage` 数据）与 `roomDoorPoint(w,room)`（普通房间用 `campEntrance` 门中心；facility 用 `facilityGate`）。
- 客户端：正式室内移动改走 `roomSpaceFor(site)` + `moveRoomSurface`；`IPOS` 仍是像素渲染坐标，只在边界 `/16` 一次；`roomPixelWalk/moveRoomFeet/roomAllows` 只在 `?space=legacy` 与绘制遮罩里保留。进出房间是 portal 原子迁移：进门 `pos.space='room:<room>'`、门口；出门 `pos` 切到门外世界点，下一次 `player_sync` 不再被判瞬移。室内 `player_sync` 由客户端补发，服务端用 `roomSurface.walkable` 校验。

### 0.3 居民路径推进点

- `life/body.mjs`
  - `residentRoute(world,id,to,access)`：起点 = 当前 pos（室内先取房间门世界点），终点 = 目的地门/工点；`worldRoute`（A* 核心）出世界坐标路径；`allows` 用地面谓词（半径 0），体半径由逐帧/`playerReach` 负责。
  - 正式 `startMove`：写 `districtTravel = {from,to,arrive,kind,length,start,path,index,cursor,destination,at}`；`arrive = w.t + max(2, ceil(路径长度/unitsPerTick('walk')) + 1)`（与 P2b travelTicks 同口径）。
  - `advanceTravels(w)`：`worldTick` 每刻按同一 `speedBudget` 逐段推进、每刻写 `pos`；路径走完且到达刻到点后 `settleTravel` 才写 `loc/occupancy`、`residentTravel`。
  - 冲刺：居民固定走 `walk` 档（22.5/刻）；`sprint`（39.375/刻）仍只属于玩家移动上报，是否冲刺按 P2b 的平衡闸门保留为玩家能力；`P2B_RESIDENT_SPEED=sprint` 只是证据探针，不进默认游戏。
  - 每刻寻路预算 `P2C_ROUTE_BUDGET_MS=120`（跨世界共享），`worldRoute/pixelPath` 支持 deadline；超时退回无路径锚点到达（不会卡住世界）。可走性按 0.5 单位点缓存、路径按 (start,dest) 缓存。
- 研究态保持旧 `12/刻 + 锚点到达`（无 `path`），逐位不变。

## 1. 这一刀改了什么

### 1.1 唯一位置（新文件 `life/actor-pos.mjs`）

- 事实 `w.pos`，空间 `'world' | 'room:<room>'`；研究态不建。
- 派生索引：`loc`、`occupancy`、`playerPos`、`campPlayerRoom`、`districtTravel`、`residentTravel`；`constructionArrivals` 只读派生。
- 旧档迁移 `migratePositions`、旧位置字段静态闸门（`P2c-03`）。
- 玩家进出房间/设施：`survplay-camp` 的 `move`/`camp_exit` 改为 portal 迁移；室内 `playerReach` 用 `roomSurface` 判家具/墙。

### 1.2 房间空间（新文件 `shared/room-layout.mjs` + `life/space.mjs:roomSurface`）

- 16×12 世界单位 + 唯一门 portal；家具规格从 `web/app.js` 移到 shared，`web/hall-front.mjs` 变兼容层。
- 服务端 `roomSpaceOf` 与客户端 `roomSpaceFor` 用同一 `roomStage`/门/栏杆数据。
- 客户端正式室内路径（wasd/点击走近家具/出屋）改走 `roomSurface`，legacy `?space=legacy` 保留。

### 1.3 居民连续移动（`life/body.mjs`、`life/survplay.mjs`）

- `startMove` 从"直线距离/12 刻锚点到达"改为"space 路径逐段推进 + 同一 speedBudget"。
- `worldTick` 每刻 `advanceTravels`；到达才同步 `loc/occupancy`；`settleTravel` 再做一次施工可达性校验。
- 每刻寻路预算 + 点/路径缓存，把单刻阻塞控制在与 P2b 同档（见 §3.1）。
- 研究态显式保留旧路径。

### 1.4 A* 单入口

- 核心只剩 `shared/asset-collision.mjs` 的 `pixelPath`（加可选 deadline）；世界坐标窗口搜索 `worldRoute` 也在同一文件。
- `shared/camp-outskirts.mjs` 的 `joinedRoute` 变为 `export { worldRoute as joinedRoute }`，不再含寻路实现。
- `web/walk.mjs` 的 `astar` 仍是唯一的 tile 薄包装（`pixelPath` 转向点展开）。
- `P2c-08` 断言 `joinedRoute === worldRoute`、`camp-outskirts` 不含 `pixelPath(`/`function joinedRoute`、`walk.mjs` 只有一个 `astar`。
