## 5. 加载/帧率验收（真实 Chrome + CDP）

### 5.1 先纠正口径：P2c 金样的 861/1467 不是可比数字

P2c 金样（`evidence/redo-p0/p2c-final.json`）的 `first3d` 是：survival 场景**冷缓存第一页**、title 场景**第三个页面且前面页面没有关闭**（前一页的 `requestAnimationFrame` 动画仍在跑）。P0 的 643/990 也是同一套顺序里的不同位置。跨 commit 直接比 861 vs 643 会把“机器负载/场景顺序/前一页抢 CPU”算到 P2c 头上。

本轮重写 `scripts/p3-perf-browser.mjs`，用**同一 harness**在 P0 `93dd599`、P2c `0dc76c4`、P3 当前各跑一遍；每个场景先 `Target.closeTarget` 关掉上一页，冷/热分开量：

- `cold survival`：全新 Chrome，第一张页面就是 `/?mode=survival`；
- `warm title`：同一 Chrome 再开 `/`（HTTP 缓存热，等价于金样的 title 第三场景，但不让 survival 页继续跑）；
- `cold title`：再换全新 Chrome，第一张页面就是 `/`；
- `click→首帧`：菜单就绪后真实 `click` `#startSurvival` 到 `#cvA` 首次 `data-renderer='3d'`。

### 5.2 同 harness 结果（headless=new + `--disable-gpu`，ANGLE Microsoft Basic Render Driver）

| 场景/指标 | P0 `93dd599` | P2c `0dc76c4` | P3 当前 |
|---|---|---|---|
| cold survival 首帧 | 820.9 ms | 833.4 ms | **825.2 ms** |
| warm title 首帧 | 606.7 ms | 606.5 ms | **602.9 ms** |
| cold title 首帧 | 707.3 ms | 706.7 ms | **695.4 ms** |
| click 继续生存 → 首帧 | 607.4 ms | 691.7 ms | **638.7 ms** |
| buildWorld p50（7/123456/654321） | 246.6 ms | 250.6 ms | **248.5 ms** |
| buildWorld max | 248.2 ms | 269.5 ms | **249.4 ms** |
| 首屏请求（cold survival / cold title） | 61 / 55 | 64 / 58 | **50 / 46** |
| 室外移动 fps（均值） | 31.0 | 30.6 | **32.4** |
| rAF p50 / p95 / >50ms 长帧 | 33.3 / 50.0 / 5 | 33.3 / 50.0 / 4 | **33.3 / 50.0 / 4** |

**结论**：P2c 的 actor.pos/roomSpace/居民路径**没有**把首帧拖慢；同 harness 下 P3 的 cold survival 还比 P0 快约 4ms、warm title 快约 4ms。P3 删壳带来的真实收益是**首屏请求 64→50**，并把“金样跨口径”造成的假回退消掉。

### 5.3 目标对照（真实值，不粉饰）

| 目标 | 实测 | 判定 |

| `buildWorld < 300ms` | p50 **248.5ms**，max 249.4ms | **达标** |

### 5.5 尝试过的修复（如实）

- 删 13 个 shim：首屏请求 64→50、cold survival 833→825、warm title 606.5→602.9（保留）。
- 把 `loadAssets()` 延后到首帧之后：cold survival 837.5→804.4（省 33ms），但 warm title 614.8→625.3、cold title 704.6→714.6（变慢），不稳定，**已回退**，不写进运行路径。
- 其他候选（本轮未做，避免为验收改画面/架构）：把标题世界预生成或移入 Worker；WebGL shader 预编译/首帧前 warm draw；把首帧 canvas 降 DPR；bundling/preload critical modules。gzip/brotli 只影响网络（本地 1–2ms），对 213ms buildWorld + 280ms 首绘没有帮助；critical CSS 已只有 1 个 `app.css`；DPR 策略对标题固定 `scale≤1` 的 canvas 也无收益。
