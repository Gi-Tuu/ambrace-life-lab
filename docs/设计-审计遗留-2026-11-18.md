# 审计遗留设计（2026-11-18）

> 2026-11-18 晚 V7.3 收口：下面三项**已落地代码与测试**（不是只设计）。逐项状态、回滚点与实测见文末「V7.3 收口」。研究态五份基线未动。

## 1. camp_* 全量走 rules.validate
- 现状：`survplay` 对 `camp_*` 提前返回，`rules.validate` 不认这些 kind；已有位置/成本/注册检查（PLAYER_TIME、campAction、playerReach）。
- 解耦：将 `PLAYER_TIME` 从 `survplay` 抽到独立 `action-catalog.mjs`，`rules.mjs` 只依赖 catalog + world；`validateCamp(world, body)` 负责 kind/from-to/距离/工具/库存的前置裁决，`campAction` 只执行。
- 阶段：① 只接高风险 `animal_slaughter`/`camp_take`/`camp_store`（validate 后仍保留原有拒绝码）；② 全量 camp_* 迁移，保持返回码兼容；③ 删除 survplay 的提前 return，统一入口。
- 风险：循环依赖（body→survplay→rules）、拒绝码变化破坏前端契约、成本表重复。测试策略：每个 camp_* 的 validate 单元 + 现有 camp-parity/浏览器回归。

## 2. 持久化全异步
- 现状：`saveChain` 串行 + `ACT_SAVE_COALESCE_MS` 合并；tick 写入仍可能竞争。
- 设计：tick 结束只入队 `{campKey, revision, dump}`；单写者按 revision 原子提交（unique tmp → fsync → rename）；内存 ring 保留最近 N 个 revision；崩溃时启动扫描 `*.tmp`/journal，选最大完整 revision；读路径返回最后已提交快照，不排队等写。
- 性能目标：/world p95 <50ms（写不阻塞读）；tick 写入 p95 <10ms；崩溃恢复 <1s；队列上限/超时丢弃旧 revision。
- 风险：丢最后若干 tick（可接受并显式暴露 lastCommittedTick）；多实例需锁。测试：写失败注入、崩溃点扫描、并发 tick/保存。

## 3. host 单例 / 服务端去 3D
- 现状：host 模块级 S；serve 静态/宿主同进程；服务端 import web 3D 模块用于锚点/几何。
- 拆分：`host-core`（世界/存档/预算）无状态工厂；`host-runtime` 持有每营地实例；serve 只做 HTTP/鉴权/路由；3D/几何抽成纯数据 `web/geometry-data` 或服务端 `life/anchors`，服务端不再 import Three/DOM。
- 迁移：先给 host 加 `createHost(dataDir)`，保留 `host` 单例适配层；再按营地分实例；最后删服务端 3D import。
- 测试：现有 host 测试双跑（单例/工厂）；路由/存档/预算隔离；启动依赖图断言无 web 3D。
- 风险：31+ 字段状态迁移、预算/模型配额全局语义、前后端锚点漂移。分期做，不在本轮硬改。

### C. 6 营地异步持久化（已完成并实测）
- tick 末尾只 `scheduleTickSave()`（`setImmediate` 单飞 + 后台串行链），不 `await save()`；`flushWrites/start/stop` 负责收口；写失败只置 `saveError`，不杀世界。
- 实测（`scripts/arch-async-probe.mjs`，故障注入 `ARCH_SAVE_STALL_MS=400`）：6 个名字营地 + 主营地，20 刻；tick 最大 **19.5ms**、p95 **19.5ms**，flush **432ms**；6 份营地档 t=20、索引 6 条、`validCampArchive` 全过、主档 `.bak` 可读。
- 中断恢复：flush 一版后，第二版存档中途 `process.exit(1)`；旧档 6/6 可读（t=10），重启后 6/6 按 key 打开。
- 证据 `evidence/arch-fix/multiproc-async.json`。风险：硬退出会丢「已排但未落盘」的最后一段 tick（最多 SAVE_EVERY 刻），这是异步写的有意取舍；需要零丢失时调用 `flushWrites()`。
- 回滚点：把 tick 末尾一行改回 `await save()` 即可退回同步语义；域模块与存档格式无需回滚。
