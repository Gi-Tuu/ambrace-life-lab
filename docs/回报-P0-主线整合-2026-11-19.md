## 2. 整合前发现并修复的主线回归（`31f67e7`）

`e38427e` 的 `drawTitleScene()` 里残留了 `be23b5e` 的相机平滑代码：

```js
const smoothKey=historical?'replay':overview?'overview':room?'room:'+site:'outdoor';
if(!camSmooth||...) camSmooth={...};
```

`historical/overview/room/site` 在标题作用域都不存在，`camSmooth` 也未声明，ES module 严格模式下每帧抛 `ReferenceError`，**标题场景在 `e38427e` 上根本画不出来**。这会让 P0 金样的 title 场景无法采集（首次 `--label before` 实测超时失败）。

修复：把平滑块移到 `drawCamp()` 真正计算 `x/z` 之后，并在 `lastCam` 旁声明 `let camSmooth = null;`。主线的相机平滑意图保留，标题不再崩。金样的“改前”基线因此是 `31f67e7`（内容等价于 `e38427e` + 这一个修复），不是纯 `e38427e`；这一点如实披露。
