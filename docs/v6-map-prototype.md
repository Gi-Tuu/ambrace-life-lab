# V6 第四批 · 荒野地图架构

## 原型范围

从生存主菜单可进入独立荒野试走。使用当前存档的地图种子、布局版本与河道锚点。原型有独立玩家坐标和相机，可用 WASD、方向键和 Shift 试走。存档及现行聚落场景继续走原入口。通过本轮原型验收后，再决定正式地图规模和迁移顺序。

## 坐标、边界和水文

保留村庄原点和已有地点坐标。原型增加带负坐标的区块，测试包络为 x=[-84,204)、z=[-84,180)，实际可走范围取决于三面山脊、南缘曲线、坡度和河流碰撞。步行、相机跟随与地表渲染共用同一组三角高度。南缘下方有崖壁、雾和河流瀑布。主河在村庄段沿用现有河轴，北侧源头接入一条在北谷汇流的支流，南段沿低地流向崖口。试走用一座对齐河轴的固定桥检验通行。

## 分区与数据生命周期

- 24×24 格为一区块，整数除法支持负坐标。相机周围最多 25 块提交渲染，外围保留地表和轮廓，靠近时补充植被细节。远近共用同一地表网格，避免接缝。
- 区块生成使用世界坐标与种子。CPU 与 GPU 分别限额缓存。玩家跨区时生成缺失块并按最近使用淘汰。当前原型同步生成，加载尖峰实测后再决定是否引入工作线程和预取队列。
- 正式整合时，将建筑地块、居民和生态源按坐标落入空间索引。静态地形只存种子与生成版本，改动仅记录已砍伐、建成、采集等事实。碰撞读取附近区块与实体占地。
- 地图导航先用区块边界的可通过点构成连通图，再在相邻区块内算细路。正式接入前验证边界窄口、桥、失败回退以及失效后的重新规划。原型保留手动探索，现行村庄寻路继续使用既有流程。
- 所有区域共用世界刻。远处生态以后按游戏日和经过刻数补算，镜头外居民使用地点级行动，近处才增加寻路和动画。继续用服务端裁决建造、资源和居住状态。
- 正式迁移时为地形单独记生成版本，既有住宅、田畦、设施保留原坐标和实体 ID。先为旧村庄保留固定地形核心，再开放外围迁移。新旧档分别验证读档后建筑、农田、桥和出生点的位置。

## 本轮验收

验证同种子重现、负坐标跨区、远近级别接缝、北东/西山地不可穿越、南侧止步、河道与桥、瀑布和流水网格。用真实浏览器记录首次可见、移动时帧间隔、区块生成耗时和缓存容量。原型达到后交付试走链接，正式规模依据实测和验收另定。


## 实测与规模裁决

Windows / Node 24.18.0 / Chrome 157，无头 SwiftShader，2.5 秒帧间隔采样。主菜单到可见 505 ms，原型导航后约 441 ms。133 个帧间隔，中位数 16.7 ms，P95 33.4 ms。区块生成 P95 3.8 ms，帧提交 P95 25.1 ms。跨 11 次区块边界并经测试定位访问多处地形，共生成 190 次区块。最多保留 42 个 CPU 区块、42 个 GPU 缓冲，当时缓存网格约 6.15 MiB，GPU 顶点缓冲约 4.95 MiB，JS 堆约 14.0 MiB。此处的网格及缓冲字节不含浏览器和驱动的其他内存。410 px 移动端模拟无横向溢出，方向控件可见。帧间隔采样包含稳定视角，不能代表连续移动的整段表现。实测从桥西步行到桥东，跨过 z=24 的区块接缝，悬崖外定位被拒。返回主菜单仍可进入原生存 WebGL 场景。

## 生存地图拼接

独立试走页已移除。生存玩家用同一个行走器、相机和游戏状态通过聚落边缘进入外围。原 120×80 格保留为聚落核心，外围按区块加载，当前总包络为 600×570 格。交界处高度归零，外围地表不覆盖聚落地表，河道沿同一轴线接入。离开聚落后当前浏览器会话保存玩家脚点，同一存档刷新可以恢复。已有建筑、田地和居民位置仍按原存档恢复。外围区域的居民自主寻路、建造和资源行为待后续接入。


## 地形和美术统一

外围地面复用聚落的 32px 草、泥、石素材，树林、灌木和草簇复用聚落模型及风动参数。地形种子影响不同尺度的高程、树木密度和河道宽度。村内河轴保持存档口径，河道出村后逐渐增加弯曲及宽度变化，水面从北向南下降。区块间共享顶点高度，现有 600×570 格包络和缓存上限继续适用。试走验证用当前生存入口。


## 统一生存地表

生存 3D 视图的每个区块均由同一高程、河道和材质规则生成，包含原聚落坐标范围。建筑、农田、桥和已有道路数据作为地表上的实体或材质分布。坡面通过建筑、菜畦等预留地块的距离局部放缓，河流继续沿村内河轴流经村外。原整村纹理仍用于 2D 和对照模式。世界全景显示完整地形包络。浏览器验证全景、村内外连续步行、脚点恢复、住宅拆路、林鸟和悬停。外围居民活动和建设仍使用原有聚落范围。
