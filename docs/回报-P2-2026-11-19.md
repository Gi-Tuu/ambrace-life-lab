## 1. 这一刀改了什么

### 1.1 新增 `life/space.mjs`：唯一空间查询（纯模块）

- 坐标：1 世界单位 = 1 tile = 16px；`roomToWorld/worldToRoom` 显式换算，房间区域固定 16×12，不再靠隐式 `/16`。
- `createSpace()` 返回：
  - `walkable(x,z,r)`：营地内查共享地面 + 实体 AABB；营地外查传入的 `wildLandscape`；带体半径。
  - `heightAt(x,z)` / `roomHeightAt(x,z,room)`：营地取 `stage.floors`（桥面/屋舍/浮雕），野外取 `wildLandscape.height`；房间地板显式 0。
  - `collidersNear(x,z,r)`：均匀网格索引，不再每次扫全表。
  - `portalAt(x,z,r)` / `roomPortal(room)`：门来自 `stage.entrances`（`campEntrance`），桥带来自 `campBridgeBounds`。
  - `terrainWalkable/classify`：water/bank/bridge/grass，供一致性抽样与排查。
- **数据源仍是现有几何的适配器，没有重写**：
  - 营地地面：`campTerrain` 的 `riverCenter/riverHalfWidth` + `hash2` 岸线噪声，公式与 `web/app.js` 的 `terrainKinds` 逐点等价（含 3px 岸带）。
  - 桥：`campBridgeBounds(layout.crossZ-1, layout.crossZ+1, …)`，与客户端 `bridgeCells` 同一来源。
  - 碰撞：`stage.boxes.filter(solid)` → `modelBounds` AABB；旋转件也走同一 `modelBounds`。
  - 高度：`stage.floors` + `floorContains`（与 `stage.heightAt` 同一实现）。
  - 野外：直接包住现有 `wildLandscape` 实例，不另造第二座山。

### 1.2 服务端 `construction-access` 改走 space（保留 fallback）

- `mapFor()` 构建 `space`：`campSurface({mapSeed,layoutVersion,layout,stage})` + `wildSurface(terrain,{crossing:layout.crossZ})`。
- `constructionAccess` / `residentConstructionAccess` 的 `ground()` 改为 `space.walkable(x,z,0)`。
- fallback：`SPACE_V1=0` 时恢复旧的“营地解析河 + 村外 wildLandscape”两套谓词；`fallback-space0.log` 证明旧路径仍 5/5 绿。
- 新增 `constructionSpace(w)` 供闸门/证据查询（正式游戏 + `campLayout`）。

### 1.3 客户端玩家移动改走 space（保留 fallback）

- `web/app.js`：`buildWorld()` 在 `w.camp` 时构建 `world.space`（几何来自现有 `scene3d` 的 boxes/floors/entrances）；构建失败或 legacy 开关时 `space=null`。
- `web/collision.mjs`：`mapAllows` / `moveMapFeet` 优先用 `world.space.walkable`；旧像素栅格分支保留。
- `web/player-move.mjs`：`campBodyWorld` 仍做体半径膨胀，但把 `space` 一起带入；路径 A* 未改（P2b 再收口）。
- fallback：`?space=legacy` 或 `globalThis.__SPACE_LEGACY__=true` 时回到旧像素栅格/旧村外限速。
- `serve.mjs` 只额外放行 `/life/space.mjs` 一个文件（不开放整个 `life/`），原有 `serve-guard` 对 `/life/host.mjs` 的 404 不变。

### 1.4 速度：正式游戏玩家统一为“单位/游戏分钟”

`space.mjs` 单一口径：

- `WALK_UNITS_PER_GAME_MINUTE = 3/8`（= 旧手感 0.5 tile/帧 × 6fps，在默认 7.5s 刻 = 3 单位/秒）。
- `GAME_BASE_UNITS_PER_TICK = 22.5`；`GAME_PLAYER_UNITS_PER_TICK = 39.375`（含冲刺 ×1.75）。
- `unitsForRealMs(ms,tickMs,sprint)`：客户端与服务端换算共用同一函数。

接入：

- 服务端 `playerReach`：正式游戏 `player_sync` 用 39.375/刻；非移动动作（采集/建造等）用基础 22.5/刻，防止“动作瞬移”。旧时间模型仍是村外 10/刻、村内 40/刻。
- 客户端：玩家步长由 `unitsForRealMs` 派生；删除“村外禁冲刺”的 `inCamp` 条件，村内/村外同一预算。`peripheralStepCap` 保留给 legacy 分支。
- 表现层在 `TICK_MS` 被冻住/超慢（金样/quickstart 的 `10000000`）时按名义 7.5s 刻换算，避免世界钟停住时玩家动画也停住。
- **居民移动仍走旧路径**（`startMove` 仍是 12/刻）。统一常数 `GAME_RESIDENT_UNITS_PER_TICK` 已从 space 导出，P2b 接居民移动时再切；这是按派单第 5 条“避免一次改两边”的取舍。

### 1.5 房间/门户

- `life/camp-play.mjs` 的室内位置判断从 `pointIn(from,16.01,12.01)` 改为 `roomContains`（显式 16×12；`SPACE_V1=0` 回退旧判据）。
- space 暴露 `roomPortal(room)` 与 `roomHeightAt(x,z,room)`；房间仍是区域，门/入口来自 `stage.entrances` 的同一份数据。

## 3. 闸门与证据（全部在 `evidence/redo-p2/`）

### 3.1 同坐标客户端/服务端一致性（10k+ 抽样，两例）

`scripts/p2-space-parity.mjs`：同一条坐标数组，同时问客户端 `buildWorld().space` 与服务端 `constructionSpace`。

| 例 | 坐标 | terrain 差异 | walk 差异 | 差异分类 | portal 差异 | 桥面高度差异 |
|---|---|---|---|---|---|---|
| host（seed 0 / v0） | 11,000 | **0** | 480 | client-collider 480 / server-collider 0 / terrain 0 | **0** | **0** |
| seed13 / v2（含桥/门） | 11,000 | **0** | 441 | client-collider 441 / server-collider 0 / terrain 0 | **0** | **0** |

- 地形（水/岸/桥/草）两例 **22,000/22,000 逐点相同**；河岸带与桥带都在样本内。
- 客户端/服务端门与桥 portal **0 差异**。
- 桥面高度 **0 差异**。
- 真实按键 0.7s：玩家移动 2.0 单位（`parity-walk.json`），未被 space 碰撞钉住。

差异清单（明确可接受项，P2b 收口）：

1. **客户端专属树/岩实体**：客户端 `scene3d` 含 `world.trees/rocks` 的 solid AABB；服务端 `construction-access` 的 `outdoorStage(trees:[])` 不含实例化树/岩。所以 480/441 个 walk 差异全部是“客户端有实体、服务端无实体”。服务端原本就忽略树（不是本刀新增），施工可达性点位在清空地块内；P2b 统一场景实体后归零。样例坐标见 `parity-host.json` / `parity-seed13v2.json` 的 `walkBuckets.client-collider.sample`。
2. **客户端山丘浮雕高度**：host 47 个 height 差异，全部来自客户端 `scene3d.floors` 的 `reliefFaces(hills)`；服务端 construction stage 不含山丘浮雕。桥面/房间地板/平地高度 0 差异；seed13/v2 height 差异为 0。P2b 地形重写时统一。
3. **未解释差异 = 0**：`walkBuckets.terrain = 0`，两例 `terrainDiff = 0`，`server-collider = 0`。

1. **居民移动/寻路未接**：`startMove` 仍 12/刻、`joinedRoute` 仍旧；`GAME_RESIDENT_UNITS_PER_TICK` 已导出待 P2b。
