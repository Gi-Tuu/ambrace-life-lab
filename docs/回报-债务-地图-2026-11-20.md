## 1. 逐条对上

### 1.1 `space` 唯一权威，正式路径删旧开关

- 正式模块导出/调用只有 `life/space.mjs`：`heightAt / walkable / collidersNear / portalAt`（外加 `terrainWalkable / surface / roomSpace`）。
- 服务端 `construction-access.constructionSpace()` 只返回 `sceneSpace(w)`；`groundQuery(w)` 只问 `space.walkable(x,z,0)`。
- 客户端 `buildWorld` 只建 `world.space`；`mapAllows/moveMapFeet` 只问 `world.space`，缺失时返回 `false`（构造错误不复用第二套几何）。
- 删 `SPACE_V1`（env）、`spaceQueriesEnabled`、`?space=legacy`、`globalThis.__SPACE_LEGACY__`、`peripheralStepCap`。研究夹具 `life/research-space.mjs` 保留旧谓词/wrapper/像素行走，正式模块 0 import。
- 静态闸门：`ARCH-SPACE-01` 逐符号变红；`evidence/debt-map/formal-scan.txt` = **239 个正式文件，0 命中**（扫描 `SPACE_V1/spaceQueriesEnabled/__SPACE_LEGACY__/space=legacy/campBodyWorld/roomPixelWalk/roomBodyFits/moveRoomFeet/roomAllows/peripheralStepCap`）。

### 1.2 同一高度链；stage.floors 只注册可站表面；客户端/服务端同输入同结果

- 地形链唯一：`campSceneContent` 的 `content.landscape`（`campTerrain + createCampOutskirts`）。服务端 `sceneSpace` 与客户端 `buildWorld` 都把它传给 `createSpace({terrain})`。
- 高度组合唯一：`heightAt = max(0, 地形链, 已注册表面)`。
  - `0` 是地面基准面；河床/洼地的负高度不参与脚底高度，村内/野外同一口径。
  - `stage.floors` 只通过 `floorSurface`（无表面 = `null`）参与组合，不再充当第二套地形。
  - 桥面：地形在桥下，桥面来自 `stage.floors` 注册表面，走上去取表面高度。
- `campSceneBundle({...})` 同时产出 `content` 与 `stage`；两边传同一组输入（`mapSeed/layoutVersion/layout/rooms/districts/peripheralHomes/households/homeRoads/ecoSources`），所以 `stage.floors/boxes` 与 `space` 的四个查询逐位一致。
- 证据：P4-02（5000 点 × 2 例，walkable/heightAt/portalAt/collidersNear 全 0）；22k parity（2×11,000 点，terrain/walk/height/portal/kind/桥面高度全 0）。

### 1.3 房间保留 16×12 + portal，正式室内只走 `space.roomSurface`

- 服务端 `roomSpaceOf` = `roomSurface({room, stage, bounds:stage.walkBounds, door:ROOM_DOOR_WORLD, extraSolids})`。
- 客户端 `roomSpaceFor` 同源同一份 `roomStage`/门数据；室内推进只调 `moveRoomSurface(space,...)`，出门判定只调 `space.portalAt(...)`。
- 删正式 `roomPixelWalk / roomBodyFits / roomAllows / moveRoomFeet` 分支；`walkInside / roomCrowd / cartAllows / sceneGuidance` 全部改问 `roomSurface`。
- 保留像素画布仅用于绘制/编辑数据（`ROOM_GRID`），不参与“能不能站”。

### 1.4 删 `campBodyWorld`，统一 space collider

- 正式路径 0 处 `campBodyWorld`；每帧复制 world 的包装删除。
- 像素栅格 `collisionGrid` 改为构建期一次生成的 `world.pathGrid`（`bodyGrid` 体半径膨胀），只服务 A* 路径，不裁决可站性。
- 碰撞统一为 `space.collidersNear`（stage solid AABB + 树/岩/建筑），玩家/居民/室内都用同一索引。
- 研究夹具 `life/research-space.mjs` 的 `legacyCampBodyWorld` 保留旧口径用于对照（P4-05 验证 `openEdge` 仍真的改变结果）。

## 2. 一个被否掉的方案（如实记录）

高度公式先试过“没有注册表面就返回地形本身（保留负高度）”，想让营地边界与野外完全连续。结果 golden 的 `survival/compare` 三张 canvas SHA 变化：全画布逐像素比较只有 **103 像素、最大通道差 3/255**（`(635,289)-(660,304)`，阴影采样处），截图肉眼一致，但 golden 45/45 会红。为同时满足“村内/野外同一公式”和“golden 逐位不变”，最终采用 **`max(0, 地形, 表面)`**：负地形统一按地面基准 0 处理，营地与野外同一公式，golden 恢复 45/45。该失败对照保留在过程日志中，不再作为实现。
